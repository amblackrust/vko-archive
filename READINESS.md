# Готовность по модулям ТЗ

Состояние на 2026-11-12. Статус выставлен по коду и тестам, не по плану. Backend: `pytest` — 719 тестов, все прошли. Тестов фронтенда и сквозных (E2E) нет.

Статусы: **Реализовано** — работает и покрыто тестами backend; **Частично** — работает, но есть известные пробелы; **Имитация** — работает на синтетических данных; **Следующий этап** — не сделано.

| Модуль | Статус | Комментарий |
|---|---|---|
| Публичные разделы (об архиве, контакты, филиалы, новости, FAQ, помощь, читальный зал, госуслуги, платные услуги, НПА, комплаенс, ссылки, символика, календарь) | Частично | Страницы и API есть. Нет прейскуранта, правил читального зала, телефона комплаенс-офицера, отчётов, галереи; новости, FAQ и политика конфиденциальности демонстрационные и ждут утверждения архивом |
| Каталог (фонд → опись → дело → документ) | Реализовано | Иерархия, фильтры, категории по ТЗ §5.3, страница документа, выдача файлов с проверкой доступа. Документы синтетические |
| Поиск | Реализовано | Полнотекст, триграммы и векторы в PostgreSQL, объединение через RRF, видны только опубликованные объекты. Векторы появляются после установки модели `bge-m3` |
| ИИ: статус и ограждения | Реализовано | `/api/ai/status`; фильтры до и после модели, ссылки и шифры вне контекста вырезаются |
| ИИ: умный поиск (разбор запроса) | Реализовано | `/api/ai/parse`, при сбое модели откат на полнотекст |
| ИИ: справка и чат | Реализовано | Локальная модель 9B: может отвечать не на языке вопроса. Без Ollama показывается «временно недоступен» |
| ИИ: вопрос по документу | Реализовано | Закрытые файлы в контекст не попадают |
| ИИ: похожие материалы | Реализовано | Без LLM, по векторам; без индекса работает запасной вариант |
| OCR | Частично | Tesseract в backend, PDF и автозапуск работают. UI статуса OCR в админке нет. В демо-данных текст скана подставлен, то есть имитация |
| Карта (филиалы, историческая карта) | Частично | Работают, но координаты не верифицированы, плитки OpenStreetMap внешние |
| Главная: вход по задаче | Реализовано | Подпись «С чего начать» и шесть чипов, сменяющиеся примеры в строке поиска (kk / ru / en). Проверено в браузере по размерам и темам, автотестов нет |
| Голосовой ввод и озвучка | Частично | Web Speech API браузера: микрофон в поиске и помощнике, «Озвучить» у ответов ИИ. Зависит от браузера (в Chrome распознавание в облаке, в части браузеров нет вовсе), распознавание казахского не гарантировано; запись и озвучка с реальным микрофоном не проверялись |
| «Как сослаться» в карточке документа | Реализовано | Архивная ссылка на трёх языках, только для открытых документов; «Л.» — общее число листов, не диапазон |
| Выставки | Реализовано | Список, страница, экспонаты, обложки |
| Архив памяти (коллекции, личности, лента времени, карта) | Частично | Все четыре раздела работают, содержимое синтетическое. Нет данных для 8 из 11 направлений |
| Админка | Реализовано | Ресурсы каталога и контента, загрузка файлов, настройки, синонимы, аналитика, пользователи |
| Роли и права | Реализовано | 7 ролей, права по филиалам, единая проверка `authorize`, тесты на матрицу доступа |
| Согласование | Реализовано | Статусы draft → review → approved → published, возврат на доработку, архив. Машинный перевод не публикуется |
| Журнал действий | Реализовано | Запись и просмотр в админке |
| Импорт и экспорт | Частично | CSV/XLSX только для документов: предпросмотр, атомарный режим, защита от XXE и zip-бомб. Предпросмотра иерархии в UI нет; новости, филиалы и страницы не импортируются |
| Переводы (kk / ru / en) | Частично | Интерфейс и контент трёхъязычны, kk/en машинные (`machine`), нужна вычитка носителем. Страница управления переводами в админке есть |
| Кабинет посетителя | Реализовано | Регистрация, вход, избранное, подборки, история поиска, подписки, сброс пароля, подтверждение e-mail. Письма уходят только при настроенном SMTP |
| Вход через Google | Частично | Реализован (`/api/cabinet/auth/google`), работает при заданном `GOOGLE_CLIENT_ID`. Автотестов нет, вход с реальным аккаунтом не проверялся |
| Адаптивная вёрстка | Частично | Брейкпоинты, мобильное меню, колонки каталога на телефоне. Автоматических проверок нет |
| Доступность | Частично | Ссылка «К содержимому», aria-атрибуты, учёт `prefers-reduced-motion` и `prefers-reduced-transparency`. Аудит WCAG не проводился |
| Безопасность | Реализовано | argon2id, JWT в `HttpOnly` cookie, проверки доступа в сервисах, тесты `tests/security`. Принятые риски прототипа — в `docs/OPEN_ISSUES.md` |
| SEO | Частично | Заголовок задан только для страницы документа, на остальных общий заголовок сайта; `sitemap.xml`, `robots.txt`, Open Graph и hreflang нет |
| Тесты | Частично | Backend 719 тестов, включая миграции и безопасность. Фронтенд и E2E не покрыты |
| Миграция со старого сайта | Следующий этап | Есть CSV/XLSX-импорт документов; перенос остального данными заказчика, план в [docs/MIGRATION.md](docs/MIGRATION.md) |

Материалы, кроме предоставленных заказчиком (`info/`), синтетические и служат для демонстрации.
