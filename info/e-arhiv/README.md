# Списки фондов с действующего сайта архива (e-arhiv.vko.gov.kz)

Открытые файлы сайта заказчика. Ссылки на них стоят в `info/Фонды.7z` (`Фонды.docx`); у четвёртого
заголовка этого документа, «Личные фонды», ссылки нет.

Получены 2026-11-11, сохранены под исходными именами, не изменялись. Данные — по состоянию на 2018 г.

| Файл | Источник | Содержание |
|---|---|---|
| `Фонды госархива ВКО на 2018г..xlsb` | <http://e-arhiv.vko.gov.kz/akimsemey/other/Фонды%20госархива%20ВКО%20на%202018г..xlsb> | Лист «Фонды»: 3754 строки, по строке на каждое название фонда (1538 фондов) |
| `парт фонды госархива ВКО на 2018г..xlsb` | <http://e-arhiv.vko.gov.kz/akimsemey/other/парт%20фонды%20госархива%20ВКО%20на%202018г..xlsb> | Лист «Фонды»: 315 строк, 153 партийных фонда |
| `газеты за 1935-2017.docx` | <http://e-arhiv.vko.gov.kz/akimsemey/other/газеты%20за%201935-2017.docx> | Таблица: 1466 подшивок (томов) газет за 1935–2017 гг. |

## Как используются

Файлы читает только конвертер `backend/seed/tools/convert_real_funds.py` (запускается один раз, нужен `pyxlsb`).
Он пишет `backend/seed/data/funds.json`, `party_funds.json` и `newspapers.json`; наполнение сайта
(`python -m seed`) читает только эти JSON.

## Что не публикуется

- Фонды с пометкой «с» у номера или с названием «секретный фонд» (38 фондов) не попадают ни в JSON, ни в базу —
  конвертер их только считает (`meta.skipped_restricted`).
- У фондов с пометкой «ч.с.» публикуется описание с признаком частичного ограничения; число секретных единиц
  хранения (например, «3618/34с») не сохраняется — остаётся только общее число единиц.

Подробности и принятые правила — в `docs/DATA_SOURCES.md`.
