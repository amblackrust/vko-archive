# Источники данных сайта (T2.6)

Что где берётся и что является демонстрацией. Кодом наполнения занимается `backend/seed/`
(`cd backend && .venv/bin/python -m seed`, повторный запуск ничего не создаёт).
Пометка **РЕАЛЬНОЕ** — факт из `info/` заказчика (без изменений). **ДЕМО** — вымышленное или
сгенерированное для прототипа, помечено «ДЕМО» в UI и данных. **ПРОЧЕЕ** — текст, написанный для
прототипа, не из `info/`, требует согласования с архивом.

Статусы переводов (`translation_status`): `verified` — текст на языке оригинала или проверенный;
`machine` — машинный перевод, нужна вычитка носителем; `missing` — перевода нет (на сайте показывается
оригинал и уведомление «Перевод отсутствует»).

| Блок | Источник | Статус | Переводы |

- Часы работы филиалов, кроме головного архива — в info/ нет.
- Логотип — заглушка.
