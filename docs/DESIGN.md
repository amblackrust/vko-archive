# DESIGN.md — дизайн-система публичного сайта

Утверждённый макет главной: `frontend/mockup/index.html` (открыть в браузере). Это эталон
стиля для всех страниц. Админка (`/admin`) остаётся на Inter и своей вёрстке, токены цвета общие.

## Идея
Высокая печать: хлопковая бумага, чёрная краска, вдавленный набор. Единственный цветной
акцент — красная печать архива. Сайт серьёзный и спокойный, без декоративных трюков.
Аудитория — люди 30–50 лет и старше: крупный текст, явные кнопки, привычные паттерны.

## Токены (frontend/src/app/globals.css)
- Цвета через Tailwind: `bg-background` (бумага), `bg-surface` (лист), `bg-surface-muted`,
  `text-foreground` (краска), `text-muted-foreground`, `border` (линия), `bg-primary`/`text-primary-foreground`
  (краска/бумага — главные кнопки), `text-accent` / `bg-accent-soft` (красная печать: hover, даты, пометки),
  `bg-desk`/`text-desk-foreground`/`text-desk-muted` (тёмный подвал).
- Тени: `shadow-lift`, `shadow-lift-hover` (лист на бумаге), `shadow-well` (вдавленное поле).
- Тёмная тема поддерживается теми же токенами — не хардкодить hex в компонентах.

## Шрифты
- `font-serif` — Cormorant Garamond: весь текст и заголовки публичной части (уже по умолчанию).
- `caps` (утилита) — Cormorant SC: навигация, кнопки, подписи полей, даты, крошки, короткие метки.
- Внутри `.site-public` шкала Tailwind увеличена: `text-sm` ≈ 17 px, `text-base` ≈ 19 px,
  `text-6xl` ≈ 76 px. **Не использовать `text-xs` для основного текста**; минимум для текста — `text-sm`.
- Запрещено: моноширинные шрифты, UPPERCASE с трекингом как «надзаголовки», технические подписи.

## Утилиты
- `inked` — крупные заголовки (h1, h2 разделов): краска с рельефной кромкой (SVG-фильтр в SiteShell).
- `press` — вдавленный мелкий текст на бумаге (абзацы на листах, подписи).
- `sheet` — бумажный лист (карточка/панель) с фактурой и тенью. Вместо `rounded-lg border bg-surface`.
- `well` — вдавленное поле (поиск, ввод, select).
- `ink-link` — ссылка с постоянной тонкой линией; `rule-hover` — красная линия выезжает при наведении
  (пункты меню, вкладки, переключатели; `aria-current="page"` даёт постоянную тонкую линию).
- `animate-settle` — мягкое появление (только для первого экрана, не на каждом элементе).

## Компоненты
- `PageHeader` (`components/layout/page-header.tsx`) — шапка каждой внутренней страницы:
  крошки, большой заголовок `inked`, необязательный `lead`, `actions`. Используй его вместо
  самодельных `<Breadcrumbs/> + <h1>`.
- `Button` — `primary` (краска, капитель; одно главное действие на экране), `outline` (рамка краской),
  `ghost`, `link`. Высота ≥ 44 px.
- `Input` — вдавленное поле. `select` оформлять так же (`well rounded-md h-11 px-3.5`), со своей стрелкой.
- `DemoBadge` — штамп «ДЕМО/перевод/ИИ». Пометки из ТЗ обязательны — оставлять.
- `StateView`/`EmptyState`/… — системные состояния (уже в стиле).

## Правила UX (главное)
1. **Без пояснялок.** Под заголовком страницы, вкладки, карточки, раздела не пишем описание,
   если название понятно само («Новости», «Контакты», «Каталог» — без подзаголовков).
   Текст оставляем только когда он сообщает новое: условие, срок, куда ведёт ссылка (внешний сайт),
   юридически обязательная оговорка, пометка ДЕМО/ИИ/перевод из ТЗ.
2. **Меньше блоков.** Каждый экран отвечает на одну задачу. Убираем дубли (одна и та же ссылка
   трижды), лишние «вступления», виджеты ради виджетов. Длинные списки — списком со строками,
   а не сеткой одинаковых карточек.
3. **Привычные паттерны.** Список строк с линией-разделителем, таблица «подпись — значение»
   (`dl`), вкладки с подчёркиванием, обычный `select`, кнопка-краска. Никаких «бумажек под углом».
4. **Карточки (`sheet`)** — только для объектов с картинкой или собственными действиями
   (выставка, документ с превью, коллекция). Иконки lucide — `strokeWidth={1.5}`, без кружков-подложек.
5. **Наведение заметно:** цвет → `text-accent`, линия `rule-hover`/`ink-link`, лист приподнимается
   (`hover:-translate-y-1 hover:shadow-lift-hover`). Переходы 200–300 мс.
6. Цели нажатия ≥ 44 px, фокус виден, мобильная ширина 390 px без горизонтальной прокрутки.
7. Изображения архивных документов показываем как есть (без фильтров). Декоративные фото не нужны.
8. Ритм страницы: `container-page`, вертикальные отступы секций `py-12 sm:py-16`, разделитель секций —
   тонкая линия `border-t` внутри контейнера, заголовок секции `inked text-3xl sm:text-4xl`.

## Что не меняется
Запреты ТЗ (CLAUDE.md): нет форм заявлений/заказов/оплат, внешние ссылки на eGov/e-Otinish,
пометки ДЕМО/ИИ, доступ проверяет сервер. Все строки UI — через next-intl во всех трёх локалях.
