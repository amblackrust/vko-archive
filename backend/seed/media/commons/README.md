# Изображения с Викисклада (Wikimedia Commons)

Все изображения в этой папке получены исключительно с Викисклада (https://commons.wikimedia.org) через его открытый API и используются как демонстрационные материалы прототипа сайта Государственного архива Восточно-Казахстанской области. Это исторические фотографии, гравюры, открытки и карты XVIII — начала XX века (Усть-Каменогорск, Алтай, Зайсан, Бухтарма, Семипалатинская область), фотографии военных лет, современные виды города и региона, а также государственные символы Республики Казахстан. Файлы сохранены в уменьшенных версиях (ширина не более 1920 px); часть файлов переведена из GIF/PNG в JPEG/PNG, две открытки (`oskemen-view-from-cathedral-postcard.jpg`, `oskemen-view-from-fire-station-postcard.jpg`) вырезаны из фотографии музейной витрины, для флага и герба рядом с PNG лежит исходный SVG. Других изменений в изображения не вносилось.

Отбирались только файлы, у которых на Викискладе явно указана свободная лицензия или статус общественного достояния: Public domain (PD-old, PD-Russia, PD-RU-exempt, PD-KZ-exempt, «No known copyright restrictions» библиотечных собраний), CC0, CC BY и CC BY-SA любых версий. Файлы с условиями fair use, NC, ND, с отсутствующей или неясной лицензией не использовались. Для каждого изображения автор, лицензия, ссылка на текст лицензии и ссылка на страницу файла на Викискладе записаны в `manifest.json` (поля `author`, `license`, `license_url`, `source_url`) — при публикации изображения нужно показывать эти сведения рядом с ним, а для лицензий CC BY-SA производные материалы распространять на тех же условиях. Описания в манифесте составлены по описаниям файлов на Викискладе; неуверенные датировки помечены флагом `date_uncertain`. В Казахстане нет «свободы панорамы», поэтому снимки современных зданий и памятников (они перечислены в отчёте о подборке) перед публичным запуском сайта стоит дополнительно проверить.
